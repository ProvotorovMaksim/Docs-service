# Docs Service — генерация PDF из событий Kafka

## Назначение проекта

Формирует PDF-документы из HTML-шаблонов и данных, полученных от других компонентов системы.

## Функциональность

Читает сообщения Kafka, разбирает шаблон и контекст, рендерит HTML в Jinja2 и сохраняет PDF через WeasyPrint, публикует результат.

## Архитектура

`main.py` запускает `kafka_consumer.py`. `document_generator.py` отвечает за преобразование данных, `kafka_producer.py` отправляет путь к файлу. Чтение и запись настроены на `multi-partition`. База данных отсутствует.

## Технологический стек

Python 3.11 указан в конфигурации образа, Confluent Kafka, Jinja2, WeasyPrint, Pydantic Settings, Docker Compose.

## Технические решения

Jinja2 использует StrictUndefined. В результате возвращается путь к локальному файлу, поэтому для чтения другим процессом нужно общее хранилище или отдельная доставка.

## Запуск проекта

Задайте `KAFKA_BROKER_URL`, подготовьте брокер и топик `multi-partition`. Для локального запуска нужны Python и системные библиотеки WeasyPrint. Установите зависимости командой `python -m pip install -r requirements.txt`, затем выполните `python -m main`. В `dockerfile` базовый образ указан как `python3.11-slim`.
