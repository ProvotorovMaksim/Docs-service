Оценка для позиции Junior Python Developer / Integration Engineer. Основание — статический анализ исходников, сохранённых в Git на коммите `035a578`. Выводы о сценариях отказа требуют проверки в рабочем окружении.

## Сильные стороны

Генератор можно вызывать отдельно от Kafka. StrictUndefined помогает обнаружить пропущенные поля шаблона.

## Слабые стороны и архитектурные замечания

Consumer может получить собственный результат из общего топика. Если шаблон и каталог берутся из сообщения, проверьте границы доступа к ресурсам и файловой системе до подключения недоверенных отправителей.

## Что проверить на демонстрации

Разделить каналы заданий и результатов, ограничить допустимые шаблоны и пути, согласовать способ передачи PDF.
